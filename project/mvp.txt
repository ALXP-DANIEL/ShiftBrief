====================================================================
1. PRODUCT SUMMARY
====================================================================

Product name:
ShiftBrief Live

Tagline:
Multiple worker voice updates. One clean team handover.

Alternative tagline:
Turn scattered worker voice updates into one clear handover.

Problem statement:
Small teams lose important shift information because each worker remembers different issues, gives rushed voice updates, and no one combines everything into one clear action plan.

Target users:
- café teams
- retail kiosks
- repair shops
- cleaning teams
- homestay operators
- event crews
- small warehouses

Core workflow:
manager creates shift room
-> workers join from phone/tablet/laptop
-> each records/pastes update separately
-> updates are stored under one shift
-> AI merges updates
-> one action-ready handover brief
-> task tracking

This is not a generic task manager, meeting recorder, voice chatbot, WhatsApp tool, or full group-call app.

Magic moment:
Phone worker and tablet worker submit separate updates to the same room. Manager clicks Generate Combined Brief. The app turns scattered updates into one clean shift handover with tasks, risks, checklist, and follow-up message.

====================================================================
2. MVP SCOPE
====================================================================

Build only this:

1. Manager creates shift room.
2. App generates short room code and join link.
3. Worker joins room from phone/tablet/laptop.
4. Worker enters name and role.
5. Worker records voice update or pastes transcript.
6. Worker submits update.
7. Manager sees worker updates appear in the shift room.
8. Manager clicks Generate Combined Brief.
9. AI merges all updates into structured brief.
10. App extracts tasks.
11. Manager can track task status.
12. App provides non-AI fallback if AI fails.

No auth.
No payment.
No WhatsApp.
No calendar.
No payroll.
No attendance.
No full meeting/call recording.
No raw audio storage for MVP.
No complex team workspace.

Use Supabase because multiple devices need shared data.
Use polling every 3-5 seconds instead of realtime WebSocket.

9. SUPABASE SQL
====================================================================

create extension if not exists pgcrypto;

create table if not exists shift_rooms (
  id uuid primary key default gen_random_uuid(),
  code text unique not null,
  title text not null,
  team_type text not null,
  status text not null default 'open',
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists worker_updates (
  id uuid primary key default gen_random_uuid(),
  shift_id uuid not null references shift_rooms(id) on delete cascade,
  worker_name text not null,
  role text not null,
  transcript text not null,
  source text not null default 'paste',
  created_at timestamptz not null default now()
);

create table if not exists combined_briefs (
  id uuid primary key default gen_random_uuid(),
  shift_id uuid not null references shift_rooms(id) on delete cascade,
  brief_title text not null,
  summary text not null,
  risk_level text not null,
  follow_up_message text not null,
  ai_result_json jsonb not null,
  confidence numeric not null default 0,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists shift_tasks (
  id uuid primary key default gen_random_uuid(),
  shift_id uuid not null references shift_rooms(id) on delete cascade,
  title text not null,
  priority text not null default 'medium',
  owner text null,
  status text not null default 'todo',
  reason text not null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create index if not exists idx_shift_rooms_code on shift_rooms(code);
create index if not exists idx_worker_updates_shift_id on worker_updates(shift_id);
create index if not exists idx_combined_briefs_shift_id on combined_briefs(shift_id);
create index if not exists idx_shift_tasks_shift_id on shift_tasks(shift_id);

10. API ROUTES
====================================================================

POST /api/shifts
Purpose: Create shift room.
Request:
{
  "title": "Evening Café Shift",
  "teamType": "cafe"
}
Response:
{
  "ok": true,
  "data": ShiftRoom
}
Behavior:
- validate title and teamType
- generate unique room code
- insert shift_rooms row
- return room

GET /api/shifts/[code]
Purpose: Load room, updates, latest brief, tasks.
Response:
{
  "ok": true,
  "data": {
    "room": ShiftRoom,
    "updates": WorkerUpdate[],
    "brief": CombinedBrief | null,
    "tasks": ShiftTask[]
  }
}

POST /api/shifts/[code]/updates
Purpose: Submit worker update transcript.
Request:
{
  "workerName": "Aina",
  "role": "Cashier",
  "transcript": "Customer complained coffee machine was slow.",
  "source": "speech"
}
Response:
{
  "ok": true,
  "data": WorkerUpdate
}
Validation:
- workerName required max 80
- role required max 80
- transcript required min 3 max 5000
- source default paste

POST /api/shifts/[code]/analyze
Purpose: Merge all worker updates into one handover brief.
Request:
{
  "forceFallback": false
}
Response:
{
  "ok": true,
  "mode": "ai",
  "data": CombinedBrief
}
Fallback response:
{
  "ok": true,
  "mode": "fallback",
  "data": CombinedBrief,
  "warning": "AI unavailable. Used fallback parser."
}
Behavior:
- find room
- load worker updates
- set status analyzing
- try AI analysis
- fallback if AI fails
- save combined_briefs
- replace shift_tasks
- set room status brief_ready
- return brief

PATCH /api/tasks/[id]
Purpose: Update task status.
Request:
{
  "status": "in_progress"
}
Response:
{
  "ok": true,
  "data": ShiftTask
}
Allowed statuses: todo, in_progress, done.

GET /api/ai/health optional
Purpose: Check AI env configured without exposing secrets.

# ShiftBrief Live

ShiftBrief Live helps small teams turn scattered worker voice updates into one clear shift handover.

In many small businesses, every worker remembers a different part of the shift. The cashier knows a customer complained. The kitchen knows stock is low. The supervisor knows equipment needs checking. These updates are usually spoken quickly, forgotten, or scattered across devices.

ShiftBrief Live creates a shared shift room where workers can join from phone, tablet, or laptop and submit short updates. The app merges those updates into:

- one shift summary
- tasks
- issues
- risk flags
- missing information
- next-shift checklist
- follow-up message

The app follows a focused operational flow:

scattered worker updates -> structured handover -> trackable tasks
